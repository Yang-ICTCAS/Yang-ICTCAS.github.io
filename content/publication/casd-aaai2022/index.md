abstract: |
  Federated learning enables multiple clients to collaboratively train a globally generalized model while keeping local data decentralized. A core challenge is handling the heterogeneity of data distributions (non-IID) across clients, which causes local models to drift from the global objective. Following the idea of knowledge distillation, we propose a class-wise adaptive self-distillation approach that uses the global model's predictions to help local models retain global knowledge while adapting to local distributions.

summary: Proposes class-wise adaptive self-distillation to address data heterogeneity (non-IID) in federated learning, using global model predictions as soft supervision signals for local training.
